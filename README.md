# 💬 ChugliHub

**ChugliHub** is an anonymous desi chat app designed for sharing gossips, secrets, and thoughts - privately and securely. Think of it as your digital chai tapri where everyone has something to spill ☕👀

---

## 🔥 Features

- 💬 **Anonymously Chat** with others - no names, no pressure  
- 🧵 **Real-Time Messaging** via Firebase Realtime Database  
- 🧠 **Auto-Save & Smart Sync** - no messages lost  
- 💡 **Great for students, office teams, and secret societies (👀)**

---

## 🧠 Tech Stack

| Layer            | Technology                    |
|------------------|-------------------------------|
| Language         | Kotlin                        |
| UI               | XML                           |
| Architecture     | MVVM                          |
| Database         | Firebase Realtime Database    |
| Local Storage    | SharedPreferences             |

---

## 🧪 How It Works

1. Enter anonymous chat room
2. Share chuglis, memes, or rants 💀
3. All messages synced in real-time via Firebase
